# Course materials

Put your course files here, one folder per course code (no spaces), for example:

```
materials/
  IPE301/
    lecture-01.pdf
    simplex-notes.pdf
  IPE303/
    slides-week1.pdf
```

Then open a course in Shikhor, go to **Materials** and choose **Add from GitHub**.
Shikhor opens the matching folder automatically.

Files in a public repository can be seen by anyone, so only upload things you are allowed to share.
Single files must be under 100 MB.
